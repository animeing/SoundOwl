# Layout Baselines

These PNG files are generated in dark mode with synthetic test data only.
Source revision: `fd9ec642c911d8e8f6ca24a12c993ea64aeb9c8c`.
The update script routes API, media, and WebSocket requests to synthetic test data.
Each route stores default.png and full-layout.png so the fullscreen/full layout control is also covered.

Do not capture or commit screenshots that contain real song titles, lyrics, artwork, or audio-related user data.

Refresh the baselines on a pull request by posting the exact comment `/update-layout-baselines`.
Run the committed comparison locally with `npm run test:layout:local --prefix frontend`.
